# ND-2 CM5 carrier board

Not started. It will begin once the TDR dongle proves the LAN7801 + 88E1512 test-port circuit ([roadmap](../../docs/roadmap.md)).

The design target is in [`docs/spec.md`](../../docs/spec.md): CM5 carrier, TDR test port (copied from the dongle), CM5 native uplink port, USB 3 hub + 2x USB-A, M.2 2230, DSI touchscreen, HDMI, USB-C PD input, 2S Li-ion with BQ25798 charger and fuel gauge.
