# Generation scripts

The Rev A schematic and PCB were generated by script, then checked in KiCad. These scripts are kept for reference and for building later revisions the same way.

> **Heads-up:** most scripts have a placeholder Windows project path hard-coded (`C:\path\to\ND2\tdr-dongle`) and expect KiCad 10's bundled Python (`C:\Program Files\KiCad\10.0\bin\python.exe`). Change the `P = ...` line at the top before running them.

| Script | Step | What it does |
|---|---|---|
| `gen_dongle.py` | 1 | Writes `tdr-dongle.kicad_sch` (label-based schematic). **Overwrites the schematic.** |
| `fix_courtyards.py`, `fix_usb_edge.py`, `fix_rj45_silk.py` | 2 | One-off clean-ups of the EasyEDA-imported footprints in `ND2.pretty` |
| `build_pcb.py` | 3 | Builds `tdr-dongle.kicad_pcb` from `tdr-dongle.net`: outline, stackup, rules, net classes, placement, planes. **Overwrites the PCB.** |
| `fanout.py` | 4 | Adds locked stub + via fan-outs from every GND / +3V3 pad to the inner planes |
| `route_start.py` / `route_finish.py` | 5 | Exports Specctra DSN, runs Freerouting 2.4.1 (needs Java 25), imports the SES |
| `fix_last2.py` | 6 | Hand-routes the two connections Freerouting left open (LAN_SW, C24 +3V3) |
| `drc_brief.py`, `drc_summary.py` | check | Runs `kicad-cli pcb drc` with schematic parity and prints a summary |
| `render_layers.py`, `render_zoom.py` | check | SVG exports for visual review |
| `export_fab.py` | 7 | Writes the fab package (Gerbers + drill zip, JLC CPL, BOM, PDFs, STEP) |
| `export_dsn.py`, `run_seq.py` | helpers | DSN export on its own; run several scripts one after another |

Because the PCB was routed by hand after these scripts ran, **re-running `build_pcb.py` will throw away the routing.** Edit the board in KiCad from here on.
